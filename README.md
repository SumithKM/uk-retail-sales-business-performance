# UK Retail Sales & Business Performance Dashboard

## Project Overview

This project analyses UK retail sales and business performance using Microsoft Excel, with a focus on retail value, sales volume, and the growth of online shopping across Great Britain.

The workbook uses retail statistics from the Office for National Statistics (ONS) to explore monthly trends, compare year-on-year growth, and understand the contribution of internet and non-internet sales.

## Project Objectives

- Analyse changes in the UK retail value and volume indices.
- Examine year-on-year retail value and volume growth.
- Compare internet and non-internet retail sales.
- Track changes in the share of internet sales over time.
- Present key performance indicators through an interactive-style Excel dashboard.

## Tools Used

- Microsoft Excel
- Data cleaning and organisation
- Data analysis
- Charts and data visualisation
- KPI reporting and dashboard design

## Workbook Structure

| Sheet | Description |
|---|---|
| README | Project information and guidance |
| Raw_Data | Original source data |
| Cleaned_Data | Prepared data for analysis |
| Analysis | Supporting calculations and analysis |
| Dashboard | Visual summary of retail performance |
| Insights | Key observations from the analysis |

## Dashboard Highlights

The dashboard includes:

- **Retail Value Index:** Monthly trend in UK retail value.
- **Retail Value vs Volume Growth:** Comparison of year-on-year growth over the latest 12 months.
- **Sales Channel Split:** Internet versus non-internet sales.
- **Internet Sales Share:** Long-term monthly trend from 2015 to 2026.
- **Internet Retail Sales Value:** Monthly sales values for the latest 12 months.
- **Retail Sales by Channel:** Comparison of internet and non-internet sales.

## Key Dashboard Indicators

## Key Learning

This project helped develop practical Excel skills in organising data, analysing retail performance, comparing business metrics, and communicating trends through visual dashboards.

It also demonstrates how business data can be transformed into clear performance indicators to support better understanding and decision-making.
